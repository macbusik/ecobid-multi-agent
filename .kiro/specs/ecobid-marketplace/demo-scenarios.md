## Technical Highlights to Mention

### AWS Services Used
- ✅ **Amazon Nova Lite** - Multimodal AI for image analysis
- ✅ **AWS Lambda** - Serverless compute (Node.js 20 ARM64)
- ✅ **DynamoDB** - NoSQL database (single-table design)
- ✅ **S3** - Photo storage
- ✅ **Cognito** - User authentication
- ✅ **API Gateway** - HTTP API
- ✅ **EventBridge Scheduler** - Automated lottery execution
- ✅ **Amplify Hosting** - Frontend deployment

### Key Features
- 🤖 **AI-Powered Listing** - Upload photo → AI generates title, description, category
- ⚖️ **Fair Lottery System** - Equal chance for everyone, no first-come-first-served
- 📱 **Mobile-First** - Optimized for smartphones, works on desktop
- 🔒 **Secure** - JWT authentication, user-scoped data access
- 💰 **Cost-Effective** - Runs on AWS Free Tier (<$5/month)
